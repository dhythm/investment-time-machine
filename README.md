# investment-time-machine

「あの時、あの指数に積み立てていたら今いくら？」を計算してグラフで見せる Web サービス。個人開発プロジェクト。

## コンセプト

- 開始年・毎月の積立額・対象指数を選ぶと、元本と評価額の推移をグラフ表示する
- 対象指数の例：S&P 500、日経平均、TOPIX、MSCI ワールド（全世界株式）など
- 一括投資との比較、暴落局面（リーマンショック、コロナショック等）で始めた場合の比較など、遊べる切り口を用意する
- 結果はシェアしたくなる形（サマリー表示、URL への条件エンコード）にする
- 投資助言ではなく、過去データによるシミュレーションであることを明示する

## 技術方針

- Vite + React + TypeScript の静的サイト。計算はすべてブラウザ内で行う
- 指数の月次データは静的データセット（JSON）として同梱し、外部 API 課金なしで完結させる
- データは無料で取得できる公開ソース（例：Stooq の CSV）から取得し、出典と取得日をデータファイルに記録する。配当・為替の扱い（価格指数かトータルリターンか、円建てか現地通貨か）を明示する
- UI はライトモード基調

## 開発の進め方

- 実装は Codex CLI（gpt-6.2-astra / Ultrafast）に委任し、成果物をレビューして取り込む
- 小さな単位でコミットし、main は常に動く状態を保つ
- 計算ロジック（積立シミュレーション）には単体テストを付ける

## まず作るもの（v1）

1. データ取得スクリプトと月次データセット（まず S&P 500 と日経平均）
2. シミュレーション計算（毎月積立、月初購入の前提を明示）
3. 入力 UI（開始年・積立額・指数）＋推移グラフ＋結果サマリー
4. 条件を URL にエンコードしてシェアできる形

### データについて

- 取得は `node scripts/fetch-data.mjs`（Yahoo Finance の chart API、無料・キー不要）
- 当初予定の Stooq CSV は 2026-11 時点でブラウザ検証（JS チャレンジ）が必須となりスクリプトから取得できないため、代替ソースに切り替えた
- S&P 500：1985-01〜2026-10（502か月）、日経平均株価：1984-12〜2026-10（503か月）
- 各月の `buy`＝月初（最初の営業日）の始値、`close`＝月末（最後の営業日）の終値。当月（未確定）分は含まない
- いずれも価格指数（配当を含まない）。S&P 500 は米ドル建て指数だが、為替変動は考慮せず積立額（円）をそのまま購入に充てる「為替中立」の計算（画面にも明示）

### 試算例

2000年1月から月3万円を積み立て、2026年10月末で評価した場合（元本はいずれも 322か月 × 3万円 ＝ 966万円）：

- S&P 500：最終評価額 約4,312万円（損益 +約3,346万円、+346.4%、最大ドローダウン 44.6%）
- 日経平均株価：最終評価額 約3,566万円（損益 +約2,600万円、+269.2%、最大ドローダウン 49.3%）

## v2 の状態（2026-11-24 完成）

v1 の残課題のうち、以下を実装した（デプロイは依頼者の判断で見送り、ローカル確認のみ）。

- **円建て計算**：S&P 500 と全世界株式（いずれも米ドル建て）で「為替中立／円建て（ドル円換算）」を切替可能。ドル円は FRED DEXJPUS（日次正午買いレート）を月次集計した `src/data/usdjpy.json`（1985-01〜2026-10、502か月）を使い、購入時は月初レート、評価時は月末レートで換算。URL パラメータ `fx=jpy` で共有可能
- **指数の追加**：
  - TOPIX：指数そのものの無料データが取得できないため TOPIX 連動 ETF で代替。当初採用した 1306 は Yahoo データが分割で不連続（見かけ上約90%の下落や異常な月末値）だったため、系列が連続しているダイワ上場投信-TOPIX（1305）に切り替えた。2007-12〜2026-10（227か月）、価格ベース
  - 全世界株式：MSCI ワールド（先進国のみ）の代わりに、新興国を含む MSCI ACWI 連動 ETF（iShares ACWI）の価格を採用。2008-03〜2026-10（224か月）、米ドル建て価格ベース
- **一括投資との比較**：トグル ON で、積立総額と同額を開始初月に一括投資した場合の推移（破線）と最終評価額カードを表示。URL パラメータ `lump=1` で共有可能
- **暴落スタート・プリセット**：開始年プリセットボタン（ITバブル直前 1999年／リーマンショック直前 2007年／コロナショック直前 2019年／コロナショック後 2020年）。データ範囲外の指数では無効化される
- **チャンク分割**：グラフを遅延読み込みに分離し、最大チャンク 424kB でビルド警告は解消

### v2 試算例

2000年1月から S&P 500 に月3万円（元本 322か月＝966万円、2026年10月末評価）：

- 円建て：最終評価額 約6,408万円（+563.4%、最大ドローダウン 52.4%）。一括投資なら 約7,717万円
- 為替中立（v1 と同じ）：最終評価額 約4,312万円（+346.4%）。一括投資なら 約4,984万円
- 円建ての方が大きくなるのは、この期間にドル円が約102円→約157円と円安に進んだ分が上乗せされるため

その他の例：全世界株式（ACWI）円建て・2010年開始・月3万円 → 元本606万円が約2,122万円。TOPIX（1305代替）・2010年開始・月3万円 → 元本606万円が約1,573万円（一括なら約2,607万円）

## v3 の状態（2026-11-24 完成）：複数指数の同時比較

- 指数選択を色分けチップの複数選択に変更（最低1つ必須）。開始年・積立額・為替モード・一括比較は全指数共通の前提
- データ開始年が共通開始年より後の指数（TOPIX 2007年〜、全世界株式 2008年〜）はデータ開始月から積み立てるため、指数ごとに積立月数・元本が異なりうる。比較表と注記で明示（※v4 で下記のとおり共通開始月への統一に変更）
- 為替の円建て換算は米ドル建て指数（S&P 500・全世界株式）にのみ適用し、日経平均・TOPIX には影響しない
- グラフは指数ごとの色で実線（積立）を重ね描き。元本は最長系列の1本のみ。一括比較は同色の破線で描く（色＝指数、線種＝積立/一括）。指数は最大4つのため線は最大でも 4色×2線種＋元本1本に収まる
- 2つ以上選択時は比較表（最終評価額／元本／損益／損益率／倍率／最大ドローダウン／積立月数／一括の最終評価額）を表示し、最終評価額が最大の行をハイライト。1つだけの選択時は v2 のカード表示のまま
- URL は `idx=sp500,nikkei225` のカンマ区切り（v1/v2 の単一指定 URL もそのまま読める）

### v3 試算例

2020年開始・月3万円で S&P 500／日経平均／全世界株式を重ねた場合（いずれも82か月・元本246万円、2026年10月末、為替中立）：

- 日経平均株価：約431万円（+75.2%、1.75倍、最大ドローダウン 17.0%）
- S&P 500：約409万円（+66.4%、1.66倍、最大ドローダウン 8.4%）
- 全世界株式（ACWI）：約379万円（+54.2%、1.54倍、最大ドローダウン 7.7%）

円建てモードに切り替えると、米ドル建ての2指数だけが円安の分だけ押し上がり、S&P 500 は約506万円（2.06倍）で日経平均を上回る。全世界株式は約465万円（1.89倍）。日経平均は円建てでも変わらない。

## v4 修正（2026-11-24）：比較の共通開始月への統一と検証結果

v3 の比較について「S&P 500 と日経が近く、日経と TOPIX の差が大きく、全世界が日経より下なのは本当か」という検証依頼を受けて再計算した。

- 計算自体は正しかった（依頼者の見た倍率 4.46／3.69／2.73／2.49 を再現）。ただし v3 の比較は期間が混在していた：開始年2000でも S&P 500・日経は322か月（元本966万円）、TOPIX は227か月（681万円）、全世界は224か月（672万円）
- 価格フィールドは全系列で統一されている：Yahoo Finance の月次 Open（購入）／Close（評価）の生価格で、Adj Close は不使用。S&P 500・日経平均は価格指数（配当なし）、TOPIX（1305）・ACWI は ETF の市場価格（分配金なし・信託報酬等のコストを含む）で、「配当を含まない」前提は系列間で一貫している
- 修正：複数指数の比較時は、全指数のデータが揃う共通開始月に揃える（開始年2000・4指数なら2008年3月開始、全指数224か月・元本672万円で一致）。単一選択時は従来どおり。揃えた場合は画面に注記が出る
- 共通期間（2008年3月〜2026年10月、月3万円）での倍率：S&P 500 3.62倍、日経平均 3.32倍、TOPIX 2.73倍、全世界株式 2.49倍。順位は変わらないが、これは実態である（同期間の指数値上がり率は S&P 500 5.73倍・日経 4.07倍・全世界 3.16倍・TOPIX 2.80倍。全世界は米国比率約6割で、欧州・新興国が米国に劣後したこととドル建て表示が主因。日経と TOPIX の差は、価格平均型で値がさ株の影響が大きい日経平均が時価総額型の TOPIX をこの期間上回ったという実際の市場現象）
- なお「S&P 500 と日経が近い」印象の一部は積立の性質による：2000年からの指数値上がり率は 5.44倍 vs 2.83倍と差が大きいが、積立は下落期に安く多く買うため倍率が圧縮されて見える

## v5 変更（2026-11-24）：為替モードの初期値を円建てに

- 依頼者決定により、為替モードの初期値を「円建て（ドル円換算）」に変更した（日本人ユーザーに馴染み深いため）。パラメータなしで開くと円建てになる
- 為替中立にしたい場合はトグルで切り替える。URL は、円建て（デフォルト）では `fx` を付けず、為替中立のときだけ `fx=neutral` を付ける。過去に共有された `fx=jpy` のリンクも従来どおり円建てで開く
